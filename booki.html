Contexte

Intégrer une maquette responsive en HTML & CSS

Le projet consistait à reproduire fidèlement une maquette Figma en respectant les bonnes pratiques du développement front-end. L'objectif était de créer un site entièrement responsive, sans framework ni JavaScript, en utilisant uniquement HTML5 et CSS3.

Problème à résoudre

Transformer une maquette graphique en un site web fidèle, responsive et accessible, tout en respectant les contraintes techniques et les standards du Web.

Objectif

Développer une interface compatible desktop, tablette et mobile en appliquant les bonnes pratiques :

  • HTML sémantique
  • CSS responsive (Flexbox & Grid)
  • Accessibilité
  • Validation W3C

Utilisateurs cibles

Voyageurs recherchant un hébergement ou des activités touristiques.

Technologies

Une intégration 100% web natif :

  • HTML5
  • CSS3
  • Flexbox
  • CSS Grid
  • Media Queries
  • Figma
  • Git / GitHub

Bilan

Ce que j'ai appris

Compétences techniques

  • Intégration pixel-perfect
  • Responsive Design
  • Accessibilité (HTML sémantique, alt, .sr-only)
  • Choisir entre Flexbox et CSS Grid

Méthodologie

  • Débogage avec les DevTools
  • Validation W3C
  • Versionnement avec Git / GitHub
  • Respect des standards du Web

Défis rencontrés

Composer avec les contraintes réelles

  • Adaptation de la maquette tablette aux résolutions réelles (iPad Mini)
  • Choix entre Flexbox et CSS Grid selon les sections
  • Gestion des alignements et des espacements responsives
  • Respect du pixel-perfect tout en améliorant la lisibilité sur petits écrans
